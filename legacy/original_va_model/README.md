# Original encoder VA implementation

These files are preserved unchanged as provenance for the original
RoBERTa/DistilBERT/XLM-R implementation. They import one another as sibling
modules and are intentionally kept together.

The active Qwen training entry point does not import this directory. Use
`../../va_model_code/train_model.py` for every current experiment.
